# 🎮 20 Games Challenge

Este repositório reúne meus projetos do **20 Games Challenge**, desenvolvidos com **Godot**.  
A ideia é criar 20 jogos, evoluindo em escopo e complexidade a cada pasta.

## 🚀 Objetivo

- Praticar desenvolvimento de jogos com Godot
- Evoluir habilidades de game design e programação
- Construir um portfólio com vários projetos jogáveis

## 📁 Estrutura do repositório

Cada pasta na raiz será um jogo independente.

```text
/
├─ ping-pong/   # Jogo 01 (em breve)
├─ ...          # Próximos jogos
```
